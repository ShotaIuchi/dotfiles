# tmux / Zellij 設定

tmux を優先使用、未インストール時は Zellij にフォールバック。
両方とも `C-x` プレフィックスで Emacs 互換のキーバインドに統一。

## tmux キーバインド

プレフィックス: `C-x`

### ペイン操作

| キー | 機能 |
|---|---|
| `C-x 2` | 水平分割（下） |
| `C-x 3` | 垂直分割（右） |
| `C-x 0` | 現在のペインを閉じる |
| `C-x 1` | ズームトグル |
| `C-x 4` | ペインサイズを均等化 |

### ペイン移動

| キー | 機能 |
|---|---|
| `C-x o` | 次のペインへ |
| `C-x n` | 前のペインへ |
| `C-x h/j/k/l` | 方向指定で移動 |
| `C-x ←↑↓→` | 方向キーで移動 |

### フローティング

| キー | 機能 |
|---|---|
| `C-x 6` | フローティングシェル（中央 80%） |

### セッション

| キー | 機能 |
|---|---|
| `C-x d` | デタッチ |
| `C-x C-x` | アプリに C-x を送信 |
| `C-x C-g` | キャンセル |

### コピーモード

| キー | 機能 |
|---|---|
| `M-n` | ページダウン |
| `M-p` | ページアップ |
| マウスドラッグ | 選択してコピー |

## tmux 設定

| 設定 | 値 |
|---|---|
| テーマ | Tokyo Night |
| ステータスバー | 表示（下記参照） |
| マウス | 有効 |
| スクロールバック | 50000行 |
| ペイン開始番号 | 1 |
| true color | ghostty 対応 |

## ステータスバー

| 位置 | 表示内容 |
|---|---|
| 左端 | プレフィックス押下中 / セッション名 / リポジトリ名 / ブランチ / worktree名（linked worktree時のみ） / PR状態 |
| 右寄せ | ウィンドウ一覧（`番号:ウィンドウ名`。非アクティブの出力は `!` で通知） |
| 右端 | ズーム中 / 日時 |

### PR状態表示

カレントペインのブランチにオープンなPRがあると `PR#123 approved` のように表示される
（`~/.config/tmux/status-git-extra.sh`、gh CLI が必要）。

| 状態 | 色 |
|---|---|
| approved | 緑 |
| changes（changes_requested） | 赤 |
| draft | グレー |
| open（レビュー待ち） | 黄 |

ネットワーク負荷を避けるため、結果はリポジトリ×ブランチ単位で120秒キャッシュされる。

Claude Code の実行状態はステータスバーには出さない
（Claude Code 自身のステータスラインに表示。[README.claude.md](README.claude.md) 参照）。

## プラグイン

| プラグイン | 機能 |
|---|---|
| [tpm](https://github.com/tmux-plugins/tpm) | プラグインマネージャ |
| [tmux-resurrect](https://github.com/tmux-plugins/tmux-resurrect) | セッション保存・復元 |
| [tmux-continuum](https://github.com/tmux-plugins/tmux-continuum) | 自動保存・自動復元 |

### セッション復元キーバインド

| キー | 機能 |
|---|---|
| `prefix + Ctrl-s` | セッション保存 |
| `prefix + Ctrl-r` | セッション復元 |

### 初回セットアップ

`install.sh` を実行すれば TPM とプラグインは自動でインストールされる。
以降は自動で15分ごとにセッションを保存、tmux起動時に自動復元。

## Zellij キーバインド

tmux と同じ `C-x` プレフィックスで同じ操作体系。

| キー | 機能 |
|---|---|
| `C-x 2` | 水平分割（下） |
| `C-x 3` | 垂直分割（右） |
| `C-x 0` | ペインを閉じる |
| `C-x 1` | フルスクリーントグル |
| `C-x o` | 次のペインへ |
| `C-x n` | 前のペインへ |
| `C-x h/j/k/l` | 方向指定で移動 |
| `C-x 4` | フローティングペイン |
| `C-x 6` | フローティングシェル |
| `C-x d` | デタッチ |
| `C-x C-x` | アプリに C-x を送信 |
| `C-x C-g` / `Esc` | キャンセル |
