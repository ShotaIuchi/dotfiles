# tmux / Zellij 設定

tmux を優先使用、未インストール時は Zellij にフォールバック。
両方とも `C-x` プレフィックスで Emacs 互換のキーバインドに統一。

## tmux キーバインド

プレフィックス: `C-x`

### ペイン操作

| キー | 機能 |
|---|---|
| `C-x 2` | 水平分割（下） |
| `C-x 3` | 垂直分割（右） |
| `C-x 0` | 現在のペインを閉じる |
| `C-x 1` | ズームトグル |
| `C-x 4` | ペインサイズを均等化 |

### ペイン移動

| キー | 機能 |
|---|---|
| `C-x o` | 次のペインへ |
| `C-x n` | 前のペインへ |
| `C-x h/j/k/l` | 方向指定で移動 |
| `C-x ←↑↓→` | 方向キーで移動 |

### フローティング

| キー | 機能 |
|---|---|
| `C-x 6` | フローティングシェル（中央 80%） |

### セッション

| キー | 機能 |
|---|---|
| `C-x d` | デタッチ |
| `C-x C-x` | アプリに C-x を送信 |
| `C-x C-g` | キャンセル |

### コピーモード

| キー | 機能 |
|---|---|
| `M-n` | ページダウン |
| `M-p` | ページアップ |
| マウスドラッグ | 選択してコピー |

## tmux 設定

| 設定 | 値 |
|---|---|
| テーマ | Tokyo Night |
| ステータスバー | 表示（下記参照） |
| マウス | 有効 |
| スクロールバック | 50000行 |
| ペイン開始番号 | 1 |
| true color | ghostty 対応 |

## ステータスバー

| 位置 | 表示内容 |
|---|---|
| 左端 | セッション名 / gitブランチ / worktree名（linked worktree時のみ） / PR状態 |
| 中央 | ウィンドウ一覧（非アクティブウィンドウの出力は `!` で通知） |
| 右端 | Claude Code状態（下記参照） / プレフィックス押下中 / ズーム中 / 日時 |

### PR状態表示

カレントペインのブランチにオープンなPRがあると `PR#123 approved` のように表示される
（`~/.config/tmux/status-git-extra.sh`、gh CLI が必要）。

| 状態 | 色 |
|---|---|
| approved | 緑 |
| changes（changes_requested） | 赤 |
| draft | グレー |
| open（レビュー待ち） | 黄 |

ネットワーク負荷を避けるため、結果はリポジトリ×ブランチ単位で120秒キャッシュされる。

### Claude Code状態表示（ハング検知）

アクティブペインで動く Claude Code の実行状態を右端に表示する
（`~/.config/tmux/status-claude-state.sh`）。
状態は Claude Code の hooks が `~/.claude/state/` に書き出したものを読む
（[README.claude.md](README.claude.md) 参照）。

| 表示 | 意味 |
|---|---|
| `▶ Bash 1m35s` | 実行中（最後のイベントからの経過時間付き。緑<2分 / 黄<10分 / 赤≥10分） |
| `⏸ 入力待ち 30s` | 許可プロンプト等でユーザー入力を待っている |
| `■` | 応答完了・待機中 |

tmux は Claude Code 本体がハングしても status-interval（15秒）ごとに
無条件で再描画するため、`▶` のまま経過時間が伸び続ければハングと判断できる。

## プラグイン

| プラグイン | 機能 |
|---|---|
| [tpm](https://github.com/tmux-plugins/tpm) | プラグインマネージャ |
| [tmux-resurrect](https://github.com/tmux-plugins/tmux-resurrect) | セッション保存・復元 |
| [tmux-continuum](https://github.com/tmux-plugins/tmux-continuum) | 自動保存・自動復元 |

### セッション復元キーバインド

| キー | 機能 |
|---|---|
| `prefix + Ctrl-s` | セッション保存 |
| `prefix + Ctrl-r` | セッション復元 |

### 初回セットアップ

`install.sh` を実行すれば TPM とプラグインは自動でインストールされる。
以降は自動で15分ごとにセッションを保存、tmux起動時に自動復元。

## Zellij キーバインド

tmux と同じ `C-x` プレフィックスで同じ操作体系。

| キー | 機能 |
|---|---|
| `C-x 2` | 水平分割（下） |
| `C-x 3` | 垂直分割（右） |
| `C-x 0` | ペインを閉じる |
| `C-x 1` | フルスクリーントグル |
| `C-x o` | 次のペインへ |
| `C-x n` | 前のペインへ |
| `C-x h/j/k/l` | 方向指定で移動 |
| `C-x 4` | フローティングペイン |
| `C-x 6` | フローティングシェル |
| `C-x d` | デタッチ |
| `C-x C-x` | アプリに C-x を送信 |
| `C-x C-g` / `Esc` | キャンセル |
