# Ask-Sub - コンテキスト分離型コマンド

作業中にメインのコンテキストを汚さず、質問やタスクをサブエージェントに委譲するコマンド。
調査・作業過程はサブエージェント内で完結し、メインには簡潔な結果だけが残る。

## 対応範囲

- **質問**: コードベース調査、技術知識、一般質問、Web検索
- **タスク実行**: ファイル作成・編集、ルール化、テスト作成、リファクタリング等

## 実行手順

### 1. 入力の取得

コマンド引数から質問・タスクを取得する。引数がなければ AskUserQuestion で聞く。

### 2. サブエージェントの起動

Agent tool でサブエージェントに委譲する。

**サブエージェントタイプの選択:**

| 内容 | subagent_type | 理由 |
|------|---------------|------|
| ファイル作成・編集を伴うタスク | `general-purpose` | Write/Edit/Bash が必要 |
| 技術知識、一般質問、Web検索 | `general-purpose` | 汎用的に対応 |
| コードベースの読み取り専用調査 | `Explore` | 高速・軽量 |

迷ったら `general-purpose` を使う。

**サブエージェントへのプロンプト構成:**

サブエージェントはメインの会話履歴を見れない。
入力の内容に応じて、メインの会話から関連するコンテキストを簡潔に添えて補う。

```
{コンテキストが必要な場合のみ}
現在のコンテキスト: {メインの会話から関連する部分を2-3行で要約}

{質問の場合}
質問: {ユーザーの質問}

{タスクの場合}
タスク: {ユーザーの依頼内容}

ルール:
- 簡潔かつ必要十分な情報を含める
- コード例がある場合はコードブロックを使う
- ファイルパスを参照する場合は正確なパスを記載する
- 不確かな情報には明示的にその旨を添える
- ファイルを作成・編集した場合は、何をしたか簡潔に報告する
```

**コンテキスト付与の判断:**
- 自己完結している（例: 「Reactのメモ化って何？」）→ コンテキスト不要
- メインの作業に関連する（例: 「さっきの内容をルール化して」）→ 関連部分を要約して添える
- 要約は最小限に。目的は入力を理解可能にすることであり、会話の再現ではない

**サブエージェントのパラメータ:**
- `model`: `"haiku"` を使う（高速・低コスト。ただし複雑なタスクの場合は省略して親モデルを継承）
- `run_in_background`: `false`

### 3. 結果の出力

サブエージェントから返された結果を**そのまま**ユーザーに表示する。
追加の解説や前置きは不要。サブエージェントの回答がそのまま最終出力になる。
